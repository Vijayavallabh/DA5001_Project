## The one rule

A reading is its interval's sign: **POSITIVE** if `lo95 > 0`, **NEGATIVE** if `hi95 < 0`, **COVERS
ZERO** otherwise. A reading **survives** iff its de-echoed reading equals its reading on record. That is
all this note decides; no tolerance on the point estimate is set and none is read. The panel count
`r` (judges with D3 POSITIVE, of five, judge B's de-echoed reading from feat-184 included) is reported
beside the registered `r = 4`.

## Gate, read before any reading

**G0.** For every `h1.py` directory read, `served_generation` decomposes `full_text` as prompt plus
generation on at least `99%` of records (`analysis/deecho_rejudge.py --coverage`, run on host B, written
to `results/deecho_rejudge_coverage.csv`). A directory below that has not been de-echoed, and the passes
that read it are reported NOT SCORED rather than as surviving or not.

## Excluded in advance

- Comparing a de-echoed level with a level on record, or across passes (caution (ap)). Only the paired
  D3 and each arm's own gain are read, as on record.
- Changing a judge, opponent, seed, `k`, prompt set or reward after any judge call; dropping a pass that
  moves.
- Re-scoring rewards on de-echoed text: selection's picks are the cached ones, as in feat-184, so the
  reward's own echo handicap (feat-184's scoring log) is left in place and stated.
