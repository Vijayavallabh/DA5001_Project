# Manuscript snapshot (ICLR 2027)

The manuscript itself lives at `~/sub/satml/` and is **not** under version control: that directory
sits inside an unrelated git repository which must never be committed to, so the `.tex` sources had
no history and no backup at all. This directory is a **copy**, kept in this repo purely so the paper
has version history alongside the results it cites.

`~/sub/satml/` remains authoritative. Edit there, compile there, and refresh this snapshot with
`scripts/snapshot_manuscript.sh`. Nothing here is compiled and nothing reads it.

Excluded from the artifact build.
